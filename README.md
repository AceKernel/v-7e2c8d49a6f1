# Reference archive

University of Queensland ECON2050 Mathematical Economics course sources and supplementary references.

**Start with [INDEX.md](INDEX.md)** for topic routing and direct links.

This archive contains complete Lectures 1-11, Tutorial 2-11 solution PDFs, Logic, Notation and the annotated revision lecture, including appended handwritten examples. Original PDFs retain their original page order.

- [Checked course guide](COURSE-GUIDE.md): a compiled, source-referenced companion, not an official key.
- [Graph presentation guide](GRAPH-STYLE.md): course-style sketches and original examples.
- [Source manifest](SOURCE-MANIFEST.json): original-PDF pages, sizes and SHA-256 checksums.

## Transcript accuracy

Every course PDF has an accompanying Markdown search transcript with PDF-page labels. Automatic transcripts are NOT verified LaTeX transcriptions: equations, exponents, matrices and figures may not survive extraction. The revision scan uses explicitly unverified OCR. Check original PDFs and the checked guide before relying on a formula. The checked guide supplements, not replaces, complete lectures and official tutorials.

## Missing or excluded

Tutorial 1 and a standalone final/past-exam paper were not included in the sources supplied for this initial archive. Revision examples are not a final-exam paper. Personal timetables, access arrangements, student submissions and unrelated courses are excluded.
