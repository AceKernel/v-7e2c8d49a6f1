Convex sets
Definition
A set S ⊆Rn is convex if for every two points of the set the line segment between the two
points belongs to the set, that is, if
∀x, y ∈S : [x, y] ⊆S,
or, equivalently, if
∀x, y ∈S, ∀λ ∈[0, 1] : λx + (1 −λ)y ∈S
