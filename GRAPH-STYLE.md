## Sketch conventions

Preserve the question's variables and axis orientation. Use arrowed, labelled axes, readable labels and a sensible range. Solve intercepts and relevant intersections algebraically; label exact values.

Draw included boundaries solid and excluded boundaries dashed. Use filled/open markers according to membership in the entire set. Shade lightly and use the question's set label. Preserve holes, separate components and unbounded directions. A pairwise LP intersection is not a feasible vertex until all constraints hold.

Use equal axis units when shape or distance matters. Disclose a schematic/unequal scale if needed; do not accidentally flatten circles. Add objective contours or tangency only when relevant. Restrained course-style colour is acceptable, but meaning must survive monochrome handwriting.

## TikZ

For requested figures use a complete \begin{tikzpicture}...\end{tikzpicture} block, outside ordinary equation delimiters. Prefer basic drawing primitives and mathematical node labels. Do not line-wrap code or substitute decorative imagery.

Include essential equations and key coordinates for handwritten reproduction. If rendering fails, give exact sketch instructions; do not claim successful rendering without evidence.
