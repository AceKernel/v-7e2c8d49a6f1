Farkas lemma
Theorem (Farkas Lemma)
Let A be an m × n matrix, b ∈Rm, and F = {x ∈Rn : Ax = b, x ≥0}. Then either F ̸= ∅
or there exists y ∈Rm such that yA ≥0 and y · b < 0 but not both.
It is useful to rephrase Farkas lemma in the following way:
Either the system of linear equations Ax = b has a non-negative solution, or the system
yA ≥0, y · b < 0 has a solution, but not both.
The system yA ≥0 and y · b < 0 is sometimes referred to as the Farkas alternative.
