ECON2050
Below some notation that we use in the ECON2050 lecture slides. It is a short and incomplete
list — I only added stuff that some of you or past students have asked me about.
(1) R
Meaning: set of real numbers
Note: The textbook by Simon and Blume (SB) uses R or R1 to denote R. See the
beginning of Chapter 2.1 of SB for an additional explanation of real numbers.
(2) N
Meaning: set of natural numbers, i.e. N = {1, 2, 3, . . .}
(3) ∈
Meaning: “is an element of”
Example: 1 ∈{1, 2, 5} means “1 is an element of the set {1, 2, 5}.”
(4) ∀(see also Tutorial 1)
Meaning: “for all”
Example: ∀x > 1, x ∈R : x2 > x means “for all real numbers x that are greater than
one, x2 > x holds”
(5) ∃(see also Tutorial 1)
Meaning: “exists”
Example: ∃ε > 0 : ε < 1 means “there exists a strictly positive number ε such that ε is
strictly less than 1”
(6) ⊆
Meaning: “is a subset of”
Example: {1, 2, 3} ⊆N (true because any element of {1, 2, 3} is also an element of N)
(7) {x ∈A : P(x)} where A is a set and P(x) some property
Meaning: The set of elements x of A that satisfy property P(x)
Examples: {x ∈R : x ≥0} is the set of non-negative real numbers; {x ∈R : x2 = 1}
is the set {−1, 1}
